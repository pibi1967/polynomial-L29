Cubic Polynomial (L = 33) – Canonical Monic Peak

Monic cubic prime-generating polynomial in canonical form

Author: Paolo Borghi · Verified run: n = 0..32 · Stop at n = 33 · Computational discovery: 3 September 2026

The Polynomial

\[P(n)=n^3+17375n^2-67426n+3247007.\]
L = 33

This monic cubic polynomial generates 33 consecutive prime values in canonical form, for \(n=0,1,\ldots,32\). The run terminates at \(n=33\), where \(P(33)\) is composite.

Termination

\(P(33)=19979261=149\cdot134089\) (composite).

Genealogical peak

The value immediately preceding the canonical run is also composite:

\(P(-1)=3331807=173\cdot19259\).

Therefore the polynomial has no effective genealogical child and is a genealogical peak in the canonical monic setting.

Form Found by the Search

The computational scan first identified the translated cubic line

\[F(n)=n^3+17381n^2+2086n+3181663.\]

with a run of 33 consecutive prime values for \(n=-2,-1,\ldots,30\). The translation \(P(n)=F(n-2)\) moves the run to the canonical interval \(n=0,\ldots,32\) and yields the polynomial above.

Computational Strategy

The final search was carried out on centered representatives of monic cubic genealogical lines of the form

\[F(n)=n^3+An^2+Bn+q,\qquad q\ \text{prime}.\]

First filter: modular obstructions for p ≤ 31

For a prime p, let Np(F) denote the number of roots of F modulo p. The search imposed \(N_p(F)=0\) for every prime \(p\le31\). In the numerical domain considered, the presence of a root modulo one of these primes obstructs a block of 32 consecutive prime values, so this is a necessary condition for the target \(L\ge32\).

The 32-tuple filter

For each prime p, define

\[ \nu_{p,32}=\#\left\{k \bmod p : F(k)F(k+1)\cdots F(k+31)\equiv 0 \pmod p\right\}. \]

If \(\nu_{p,32}=p\), every possible starting residue class of a 32-value window is obstructed modulo p, and the line can be discarded without any primality test.

A cubic has at most three roots modulo p, and each root can obstruct at most 32 starting residue classes. Hence complete coverage can occur only for \(p\le96\). After the primes up to 31 have already been treated, it is sufficient to test the new complete obstructions for primes from 37 to 89.

Modular indicators

The general modular fertility indicator used in the search was

\[ S_{97}=\prod_{p\le97}\frac{1-N_p(F)/p}{1-1/p}. \]

To evaluate specifically the configuration of 32 consecutive values, the search introduced

\[ T_{32,251}=\prod_{p\le251}\frac{1-\nu_{p,32}/p}{(1-1/p)^{32}}. \]

The second indicator was not used as a hard exclusion threshold. After the necessary filters and the broad condition \(S_{97}\ge6.30\), the surviving lines were ranked by \(T_{32,251}\) and tested in descending order. Thus the predictor determined exploration priority, not final admissibility.

Predictor calibration

Before the final scan, a calibration experiment was performed on 5,503 lines already compatible with a 32-tuple. In that sample, the Pearson correlations with the maximum run length observed in the central region were approximately:

\[ \rho(\log S_{97},L)=0.259,\qquad \rho(\log T_{32,251},L)=0.309. \]

In the top 1% of the distribution, \(T_{32,251}\) concentrated 23 cases with \(L\ge10\) and 3 cases with \(L\ge15\), compared with 17 and 1 respectively for \(S_{97}\). These results were used only as statistical evidence for search prioritization, not as a deterministic criterion.

Note on Optimality

This page documents a verified canonical run of 33 consecutive prime values for a monic cubic polynomial. No claim is made here that \(L=33\) is the absolute maximum possible, nor that no other examples with equal or greater run length exist in the literature or in independent searches.
