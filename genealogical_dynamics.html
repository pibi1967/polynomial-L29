Genealogical Dynamics of Monic Prime-Generating Polynomials

A discrete dynamical structure for monic polynomials generating consecutive primes
Documented by Paolo Borghi — Zenodo preprint, May 2026
MSC 2020: 11A41, 11Y16, 11B83

Abstract

This page summarizes and contextualizes the preprint Genealogical Dynamics of Monic Prime-Generating Polynomials, deposited on Zenodo.

The work introduces a genealogical structure for monic polynomials with integer coefficients generating consecutive prime numbers on the non-negative integers. The central idea is that the canonical translation

\[ f(n)\mapsto f(n-1) \]

induces a highly rigid discrete dynamical structure on the length of the prime sequences generated by the polynomial.

In particular, the genealogical child of a canonical monic polynomial can only:
  • increase the prime-run length by one unit;
  • or collapse immediately to \(L=0\).

As a consequence, every polynomial genealogy is finite and bounded by two collapse states. This structure naturally induces a discrete forest of isolated genealogical trees.

Overview

Prime-generating polynomials are usually studied as isolated objects: a given polynomial is tested on the sequence \(n=0,1,2,\dots\), and the number of consecutive prime values is recorded.

This work proposes a different perspective. A prime-generating monic polynomial is not viewed as a single isolated object, but as an element of a discrete genealogical structure generated by translations of the argument.

The fundamental invariant is the prime run length \(L(f)\), defined as the maximum number of consecutive positive prime values produced by \(f(n)\) starting from \(n=0\).

Prime Run Length

For a polynomial \(f(n)\in\mathbb Z[n]\), the prime run length \(L(f)\) is defined by

\[ L(f):= \max \left\{ k\ge0 \;\middle|\; f(n)\text{ is a positive prime number for every } n=0,1,\dots,k-1 \right\}. \]

If \(f(0)\) is not a positive prime number, then \(L(f)=0\). Throughout the work, only positive primes are considered; no absolute values are used.

Genealogical Child and Parent

Given a canonical monic polynomial \(f(n)\), its genealogical child is defined as

\[ g(n)=f(n-1). \]

The genealogical parent is defined as

\[ p(n)=f(n+1). \]

These two translations preserve monicity, degree, and integrality of the coefficients.

Genealogical Bifurcation Theorem

Theorem. Let \(f(n)\) be a canonical monic polynomial with \(L(f)=L>0\). Let \[ g(n)=f(n-1). \] Then exactly one of the following alternatives holds: \[ L(g)=L+1, \] or \[ L(g)=0. \] In particular, the genealogical child cannot have intermediate lengths.

Interpretation

The shift \(f(n)\mapsto f(n-1)\) introduces exactly one new value at the beginning of the sequence:

\[ g(0)=f(-1). \]

All the other values

\[ g(1),g(2),\dots,g(L) \]

correspond to the already prime values

\[ f(0),f(1),\dots,f(L-1). \]

Therefore, if \(f(-1)\) is a positive prime, the run length increases by one. If \(f(-1)\) is not a positive prime, the new polynomial fails immediately at \(n=0\), and its run length collapses to \(0\).

Inverse Genealogical Theorem

Theorem. Let \(f(n)\) be a canonical monic polynomial with \(L(f)=L>1\). Let \[ p(n)=f(n+1). \] Then \[ L(p)=L-1. \] In particular, every polynomial with \(L>1\) possesses a unique canonical genealogical parent with respect to the translation \(n\mapsto n+1\).

Genealogical Trees

In this framework, a genealogical tree is a finite linear sequence of canonical monic polynomials

\[ f_1,f_2,\dots,f_m \]

such that

\[ f_{k+1}(n)=f_k(n-1), \qquad L(f_{k+1})=L(f_k)+1. \]

Every genealogical tree is bounded by two collapse states:

\[ L=0 \to L=1 \to L=2 \to \cdots \to L_{\max} \to L=0. \]

Discrete Forest Principle

The set of canonical monic polynomials naturally organizes itself into a discrete collection of finite isolated genealogical trees.

The prime run length \(L\) therefore appears not as an isolated property of the polynomial, but as a dynamical coordinate along a genealogical translation line.

Complete Example: Cubic Genealogy with \(L=31\)

Consider the monic cubic polynomial

\[ C_{31}(n)=n^3+54n^2-2329n+20507. \]

It generates consecutive positive prime numbers for

\[ n=0,1,\dots,30. \]

Therefore,

\[ L(C_{31})=31. \]

\[ 0 \to 1 \to 2 \to 3 \to \cdots \to 31 \to 0 \]
