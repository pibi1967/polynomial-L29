The Polynomial

P(n) = n6 − 91n5 + 3437n4 − 68961n3 + 775184n2 − 4628206n + 11465323

L = 30

This monic sextic polynomial generates 30 consecutive prime values in canonical form, i.e. for n = 0,1,…,29. The run stops because P(30) is composite.

Termination

P(30) = 10007743 = 1091 × 9173 (composite).

Translation Genealogy (L = 1 → 30)

The record polynomial belongs to a translation orbit under the shift n → n − 1. Since P(-1) is composite, this polynomial has no effective child and is therefore a genealogical peak in the canonical monic setting.

Indeed, 

P(-1) = 16941203 = 107 × 158329

So the downward extension by n → n − 1 collapses immediately. The upward chain of parents exists uniquely, with lengths decreasing from 30 down to 1. Equivalently, the chain below lists the same translation orbit from the root up to the peak.
